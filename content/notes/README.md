# Notes and memories

Each film page has room for more than the Letterboxd review. To add your own
notes, memories or a longer essay for a film, create a file here named after
the film's id (the last part of its page URL):

    content/notes/deool-2011.md

Write it in plain text. Blank lines start new paragraphs. *Italics* and
**bold** work, and a line starting with "> " becomes a quote.

The notes show up under your review on the film's page the next time the
site builds.
